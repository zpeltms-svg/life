# 화성생활 내비

“내 상황에서 무엇부터 해야 할까?”에 답하는 화성시민 생활행정 웹앱입니다. **36개 서비스, 16개 빠른 메뉴, 29개 행정복지센터**를 제공합니다. 기존 제공 프로젝트를 보완했으며 원본 폴더는 변경하지 않았습니다.

## 바로 실행

Windows에서 **`실행.bat`을 더블클릭**하세요. Python이 설치되어 있으면 로컬 서버와 브라우저가 열립니다.

```bash
python local_preview.py
```

- 주소: `http://127.0.0.1:5500/index.html`
- 종료: 실행창에서 `Ctrl+C`
- macOS/Linux: `sh 실행.command` 또는 `python3 local_preview.py`
- Python 3.10 이상이 필요합니다. 이번 검증 환경은 Windows / Python 3.12.10입니다.
- 기본 실행에는 패키지 설치와 API 키가 필요하지 않습니다.
- 포트 충돌 시 `LIFE_NAVI_PORT` 환경변수를 다른 포트로 지정하세요.
- HTML 파일만 직접 열면 데이터를 읽을 수 없으므로 실행기를 이용하세요.

## 이용 방법

1. 검색창에 “아기가 태어났어요”, “주소를 바꾸고 싶어요”, “여권이 만료됐어요”처럼 입력합니다.
2. 처리 순서대로 결과를 확인하고 **자세히 보기**를 엽니다.
3. 대상·신청방법·준비서류·비용 확인 안내·담당기관·공식 출처를 확인합니다. 준비 체크는 저장되지 않습니다.
4. 화면 하단 **우리 집 관할센터**에서 읍·면·동을 선택하거나 주소를 입력합니다.
5. 센터 주소, 공식 안내와 네이버 지도 링크로 방문을 준비합니다.

출생 상황에서는 출생신고 → 화성시 출산지원금 → 첫만남이용권 → 부모급여 → 아동수당 순으로 안내합니다. 추천은 자격 판정이 아니며, 서비스별 대상 조건을 확인해야 합니다.

## 키 없이 가능한 기능과 연동 기능

| 기능 | 키 없는 실행 | 연동 시 |
|---|---|---|
| 자연어 검색·빠른 메뉴·상세·체크·인쇄 | 가능 | 동일 |
| 읍·면·동 직접 선택·센터 주소·공식 지도 링크 | 가능 | 동일 |
| 현재 위치에서 가장 가까운 센터 1곳 | 위치 정확도·생활권 검증 후 기기에서 직선거리 계산 | 동일 |
| 도로명·지번 주소의 행정동 자동확인 | 직접 선택 대안 안내 | 네이버 Geocoding + 행정동 Reverse Geocoding |
| 실시간 자동차 경로·예상시간 | 지도 웹 링크 제공 | 네이버 Directions |
| 공공데이터 추가 검색 | 로컬 검색 유지 | 정부24 공공서비스 검색 |
| AI 의도 분류 | 로컬 검색 유지 | 등록된 서비스 ID 선택만 보조 |

가까운 센터는 관할센터와 다를 수 있습니다. 기기 위치 정확도가 2km보다 낮거나 가장 가까운 센터도 12km보다 멀면 오안내를 막기 위해 결과를 표시하지 않습니다. 가까운 센터 계산에는 네트워크 전송이 없으며, 주소지 관할은 행정동 확인 결과 또는 공식 자료로 검증해 등록한 도로 규칙으로만 판정합니다.

## 선택적 API 설정 / Vercel

프로젝트 루트를 이 폴더로 지정합니다. `vercel.json`에 4개 API 라우트, 데이터 번들 포함, 보안 헤더가 설정되어 있습니다. 서버 환경변수:

```text
OPENAI_API_KEY
PUBLIC_DATA_SERVICE_KEY
NCP_MAPS_CLIENT_ID
NCP_MAPS_CLIENT_SECRET
OPENAI_MODEL                 # 선택, 기본 gpt-5-mini
```

AI 연동을 사용할 때만 `python -m pip install -r requirements.txt`를 실행합니다. 지도·공공데이터 서버 코드는 Python 표준 라이브러리를 사용합니다. 환경변수는 브라우저 코드나 저장소에 넣지 않습니다.

로컬에서는 `.env.example`을 `.env.local`로 복사한 뒤 필요한 값만 입력하세요. 실행기는 `.env.local`, `.env` 순서로 읽으며 이미 설정된 프로세스 환경변수는 덮어쓰지 않습니다. 두 파일은 Git에서 제외됩니다. 공공데이터 확장 검색을 사용하려면 공공데이터포털에서 해당 API 활용신청 후 발급받은 키를 `PUBLIC_DATA_SERVICE_KEY`에 설정하고 실행기를 다시 시작해야 합니다.

운영키 생성, 실제 유료 API 호출, Vercel 배포는 이번 검증에서 수행하지 않았습니다. 운영 연결 후 실제 키로 검색·주소변환·길찾기를 각각 확인해야 합니다. Vercel 대상 Python 버전은 `.python-version`의 3.13이며, Windows 로컬 검증 버전과 구분합니다.

## 개인정보와 보안

- 검색문은 저장하지 않습니다. 주민·외국인번호, 전화번호, 이메일, 사업자번호, 상세주소, 카드·계좌번호 형태를 양쪽에서 검사합니다.
- 개인정보 형태가 감지되면 AI 및 공공데이터 API를 호출하지 않고 로컬에서 검색합니다. 형태 탐지에는 오탐·미탐 가능성이 있으므로 개인정보는 입력하지 마세요.
- 주소 자동확인 및 실시간 길찾기는 사용자가 요청할 때 주소·위치를 지도 제공업체에 전송합니다. 가까운 센터 계산·직접 선택은 기기에서 처리합니다.
- 외부 URL은 HTTPS·credential 검사를 거치고 화면의 동적 문자열을 이스케이프합니다.
- 모든 서버 API에 본문 4,096바이트 제한, 입력 길이 제한, 호출 제한과 일반화한 오류 메시지를 적용합니다.
- 호출 제한은 프로세스 단위입니다. Vercel의 여러 인스턴스를 아우르는 엄격한 전체 한도가 필요하면 WAF 또는 공유 저장소 기반 제한을 추가해야 합니다.
- 로컬 HTTP 서버는 웹 자산 목록만 제공합니다. `.env`, Python 소스, 테스트, 디렉터리 목록은 공개하지 않습니다.

## 데이터의 확인 범위

기존 제공 자료 32개에 첫만남이용권·부모급여·아동수당·센터찾기를 추가했습니다. 공식 센터 안내의 지도 좌표를 확인하여 저장했고, **남양읍 임시청사와 동탄9동의 변경 주소**를 반영했습니다.

`SOURCE_AUDIT.json`은 공식 URL과 확인 범위를 기록합니다. 부동산거래관리시스템·인터넷등기소·무공해차 통합누리집은 이번 자동 점검에서 본문을 읽을 수 없었으므로 해당 서비스는 **재확인 필요**로 표시합니다. 기존 자료의 확인일과 이번 전체 내용 재검증을 동일시하지 않습니다. 공공데이터의 조회일도 행정내용 검증일로 표시하지 않습니다.

## 테스트

Node.js와 개발용 Playwright를 준비합니다.

```bash
python -m pip install -r requirements.txt -r requirements-dev.txt
python -m playwright install chromium
python -m unittest discover -s tests -q
node tests/search_contracts.js
python tests/e2e_app.py
python tests/e2e_resilience.py
python tests/run_backtests.py
python tests/run_reviews.py
python tests/quality_gate.py
```

E2E는 실제 로컬 HTTP와 CSP를 사용합니다. 외부 서비스 성공 응답은 명시적 모의 응답으로, 키 없음·장애 경로는 실제 로컬 서버로 검증합니다. `CHROMIUM_PATH`를 지정하면 별도 Chromium 실행 파일도 사용할 수 있습니다.

백테스트: 304개 서로 다른 자연어 문장 × 15개 독립 seed × 각 15 shuffle round. 기존 반복 실행형 리뷰를 **27개 서로 다른 품질영역 검토**로 교체했습니다. 모든 품질게이트가 통과해야 `python tests/package_release.py`가 ZIP을 생성합니다. 생성한 ZIP은 새 폴더에 풀어 전체 품질게이트를 다시 실행합니다.

검증 수치와 제한은 `QUALITY_REPORT.md`, 원시 결과는 `*_RESULTS.json`에 기록합니다. 최종 ZIP의 SHA-256과 재해제 결과는 ZIP 옆의 `.sha256` 및 `PACKAGE_RESULTS.json`으로 제공하여 ZIP 자체 해시의 자기참조를 피합니다.

## 데이터 수정

`data/services.json`에서 출처·확인일·검토기한·문맥 검색어·제외어를 함께 관리하세요. 금액이나 신청기한을 확인 없이 채우지 마세요. `data/welfare-centers.json`의 `lat/lng`는 공식 위치를 재확인한 뒤 갱신합니다. 수정 후 품질게이트와 패키징을 다시 실행합니다.
